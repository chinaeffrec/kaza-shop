## 7. Авторизация и доступ в админку

### TC-AUTH-001

- Функционал: вход в админку
- Что проверяем: успешная авторизация
- Шаги:
  1. Открыть seller-panel
  2. Ввести корректные логин и пароль
  3. Нажать `Войти`
- Ожидаемый результат:
  - открывается интерфейс панели
  - токен сохраняется
  - после перезагрузки страницы сессия сохраняется

### TC-AUTH-002

- Функционал: вход в админку
- Что проверяем: неверный пароль
- Шаги:
  1. Ввести корректный логин
  2. Ввести неверный пароль
  3. Нажать `Войти`
- Ожидаемый результат:
  - вход не выполняется
  - отображается ошибка

### TC-AUTH-003

- Функционал: выход из админки
- Что проверяем: logout
- Шаги:
  1. Войти в seller-panel
  2. Нажать `Выйти`
- Ожидаемый результат:
  - токен удаляется
  - пользователь возвращается на страницу логина

### TC-AUTH-004

- Функционал: смена учётных данных
- Что проверяем: успешная смена логина и пароля
- Шаги:
  1. Открыть `Настройки` -> `Безопасность`
  2. Ввести текущий пароль
  3. Указать новый логин
  4. Указать новый пароль
  5. Сохранить
- Ожидаемый результат:
  - данные обновляются
  - новый токен продолжает работать
  - повторный вход с новыми данными успешен

### TC-AUTH-005

- Функционал: смена учётных данных
- Что проверяем: неверный текущий пароль
- Шаги:
  1. Ввести неверный текущий пароль
  2. Попытаться сохранить новые учётные данные
- Ожидаемый результат:
  - изменения не сохраняются
  - отображается ошибка

### TC-AUTH-006

- Функционал: смена учётных данных
- Что проверяем: валидация слабого пароля
- Шаги:
  1. Указать пароль короче 8 символов или без цифр/букв
  2. Сохранить
- Ожидаемый результат:
  - сохранение блокируется
  - отображается текст ошибки валидации

### TC-AUTH-007

- Функционал: истечение токена
- Что проверяем: при невалидном токене происходит редирект на логин
- Шаги:
  1. Войти в админку
  2. Вручную очистить localStorage (или дождаться истечения через 24ч)
  3. Обновить страницу
- Ожидаемый результат:
  - пользователь перенаправлен на страницу логина
  - старый токен удалён из localStorage

### TC-AUTH-008

- Функционал: смена учётных данных
- Что проверяем: старый токен инвалидируется после смены пароля
- Шаги:
  1. Войти в админку
  2. Сменить пароль через `Настройки` → `Безопасность`
  3. Открыть админку в новой вкладке
  4. Попробовать зайти со старым паролем
- Ожидаемый результат:
  - вход со старым паролем отклонён
  - вход с новым паролем успешен

### TC-BOT-006d

- Функционал: навигация при отсутствии фото
- Что проверяем: карточки товаров без фото перелистываются корректно
- Шаги:
  1. Открыть подкатегорию, где первый товар без фото, второй — с фото
  2. Перелистнуть на второй товар
  3. Перелистнуть обратно
- Ожидаемый результат:
  - товар без фото отображается текстовым сообщением
  - товар с фото заменяет текст на фото (edit_media не падает)
  - обратный переход на товар без фото заменяет фото на текст

### TC-CART-007

- Функционал: изоляция корзин
- Что проверяем: корзины разных пользователей не пересекаются
- Шаги:
  1. `buyer_1` добавить один набор товаров
  2. `buyer_2` добавить другой набор товаров
  3. Сравнить корзины
- Ожидаемый результат:
  - корзины независимы

### TC-ORDER-003

- Функционал: checkout
- Что проверяем: обязательность адреса
- Шаги:

- Ожидаемый результат:

  - переход к созданию заказа не выполняется

### TC-ST-ORD-003
