## 1. Что это такое

Kaza Shop — готовый интернет-магазин в Telegram. Покупатели делают заказы через бота, вы управляете товарами, заказами и настройками через браузерную панель.

---

## 2. Подготовка

Перед запуском получите два обязательных параметра:

### Telegram-бот и ваш ID

1. Откройте Telegram, найдите **@BotFather**
2. Напишите `/newbot`, придумайте имя и username бота
3. Скопируйте **токен** — строка вида `1234567890:AABBcc...`
4. Напишите боту **@userinfobot** — он пришлёт ваш числовой **Telegram ID**

### В зависимости от режима запуска

| | Локально (тест) | На сервер (боевой) |
|---|---|---|
| Нужен | **Docker Desktop** | **VPS/VDS сервер** + **домен** |
| Покупатели видят бота | ❌ нет | ✅ да, 24/7 |
| SSL (https) | ❌ не нужен | ✅ автоматически |

**Docker Desktop** — скачать: [docker.com/products/docker-desktop](https://docker.com/products/docker-desktop)

**VPS/VDS сервер** — рекомендуемые параметры: 1–2 ГБ RAM, 20 ГБ диск, Ubuntu 22.04.
Провайдеры: Timeweb, Beget, Reg.ru, Hetzner. Стоимость от 300–500 ₽/месяц.

**Домен** (только для сервера) — необязателен. 
Панель управления работает и по IP-адресу сервера (`http://IP:5173`), так как она только для вас. Д
омен нужен, если вы хотите открыть публичную страницу магазина или настроить HTTPS. 
Если решите использовать домен: купите на reg.ru или nic.ru, добавьте A-запись с IP сервера — DNS обновляется до 24 часов.

## 3. Установка

### Шаг 1. Распакуйте архив

Разархивируйте `kaza_shop_release.zip` в удобную папку.

### Шаг 2. Откройте терминал в папке с файлами

- **Windows:** в папке `kaza_shop` → Shift + правая кнопка мыши → «Открыть окно PowerShell здесь»
- **Mac:** правая кнопка на папке → «Новый терминал по адресу папки»
- **Linux:** `cd ~/kaza_shop`

### Шаг 3. Запустите установщик

```bash
bash install.sh
```

Установщик предложит выбрать режим:

```
  1) 💻  Локально — на этом компьютере
  2) 🌐  На сервер VPS/VDS — для реальной работы
```

### Вопросы, которые задаст установщик

**Общие (оба режима):**

| Вопрос | Что ввести                                                       | Где взять |
|--------|------------------------------------------------------------------|-----------|
| Токен Telegram-бота | `1234567890:AABBcc...`                                           | Telegram → @BotFather → /newbot |
| Ваш Telegram ID | Числовой ID                                                      | Telegram → @userinfobot |
| Пароль администратора | Придумайте (10+ символов, буквы+цифры) - при вводе не отражается | Придумайте сами |

**Только для режима «На сервер»:**

| Вопрос | Что ввести |
|--------|-----------|
| IP-адрес сервера | Например: `185.10.20.30` |
| SSH-пользователь | Обычно `root` |
| SSH-порт | Обычно `22` |
| Способ входа на сервер | Пароль или SSH-ключ |
| Домен (необязательно) | `myshop.ru` или Enter — будет использован IP |
| Email для SSL | Ваш email (только если указан домен) |

После ответов установщик **сам подключится к серверу**, загрузит файлы и установит всё удалённо — от вас больше ничего не требуется.

### Что делает установщик на сервере автоматически

- Устанавливает Docker, Nginx, Certbot
- Разворачивает все сервисы магазина
- Настраивает SSL-сертификат (если указан домен)
- Добавляет автозапуск при перезагрузке сервера
- Настраивает ежедневный бэкап и мониторинг
- Отправляет уведомление в Telegram по завершении

### Сколько времени занимает установка

| Режим | Время |
|-------|-------|
| Локально | 3–7 минут (первый запуск) |
| На сервер | 10–20 минут (зависит от скорости сервера) |

## 4. После установки — первые шаги

### Локальный запуск

| Что | Адрес |
|-----|-------|
| Панель управления | [http://localhost:5173](http://localhost:5173) |
| Telegram-бот | Напишите `/start` вашему боту |

### Сервер

По завершении установки вы получите уведомление в Telegram со ссылкой на панель.

| Что | Адрес |
|-----|-------|
| Панель управления (с доменом) | `https://ваш-домен` |
| Панель управления (по IP) | `http://IP-сервера:5173` |
| Telegram-бот | Напишите `/start` вашему боту |

### Войдите в панель управления

- **Логин:** `admin`
- **Пароль:** тот, что вы задали при установке

### Первоначальная настройка (выполните один раз)

1. **Товары** → добавьте первые товары или загрузите из Excel
2. **Настройки** → задайте название магазина, приветственное сообщение
3. **Настройки** → загрузите QR-код оплаты (получите в приложении вашего банка)
4. Напишите своему боту `/start` — убедитесь, что всё работает
5. Оформите тестовый заказ и проверьте, что уведомление пришло в Telegram

## 5. Ежедневная работа

### Локальный запуск (на вашем компьютере)

```bash
# Запустить магазин
docker compose up -d

# Остановить магазин
docker compose down

# Посмотреть логи
docker compose logs -f

# Статус контейнеров
docker compose ps
```

### Сервер

Магазин запускается автоматически при старте сервера. Команды выполняются по SSH:

```bash
# Статус магазина
cd /opt/kaza_shop && docker compose -f docker-compose.prod.yml ps

# Логи в реальном времени
cd /opt/kaza_shop && docker compose -f docker-compose.prod.yml logs -f

# Сделать бэкап прямо сейчас
bash /opt/kaza_shop/backup.sh

# Восстановить из бэкапа
bash /opt/kaza_shop/restore.sh

# Обновить до новой версии
bash /opt/kaza_shop/update.sh
```

## 6. Управление магазином

### В панели управления вы можете:

**Товары**
- Добавить, отредактировать, удалить товар
- Загрузить до 3 фотографий на товар
- Импортировать каталог из Excel
- Включить/выключить отображение товара

**Заказы**
- Просматривать новые заказы
- Менять статус (принят → в работе → выдан)
- Отправлять покупателю товарный чек

**Статистика**
- Выручка и количество заказов за период
- Топ товаров по продажам
- Экспорт данных в Excel

**Настройки**
- Название магазина и приветственное сообщение бота
- QR-код для приёма оплаты
- Печать (факсимиле) для товарных чеков
- FAQ для бота
- Смена логина и пароля администратора

## 8. Решение проблем

### 🔴 Бот не отвечает в Telegram

Проверьте правильность токена в установщике. Перезапустите бота:

```bash
# Локально:
docker compose restart bot

# Сервер:
cd /opt/kaza_shop && docker compose -f docker-compose.prod.yml restart bot
```

### 🔴 Панель управления не открывается

Убедитесь, что Docker Desktop запущен (значок в трее), затем:

```bash
# Локально:
docker compose ps
docker compose up -d

# Сервер:
cd /opt/kaza_shop && docker compose -f docker-compose.prod.yml restart app seller
```

### 🔴 Ошибка при запуске «port is already allocated»

Порт 8000 или 5173 занят другой программой.

```bash
# Mac/Linux — найти и остановить:
lsof -i :8000
lsof -i :5173

# Windows (PowerShell):
Get-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess
```

### 🔴 Забыли пароль от панели

Откройте файл `.env` в папке магазина, найдите строку `ADMIN_PASSWORD`.

Или смените пароль прямо в панели: **Настройки → Безопасность → Изменить данные входа**.

### 🔴 Ничего не помогло (локальный запуск)

Полный сброс — **внимание: удалит все данные магазина**:

```bash
docker compose down -v
docker compose up -d
```

### 🔴 Магазин перестал работать на сервере

Вы получите уведомление в Telegram автоматически. Если не восстановился:

```bash
cd /opt/kaza_shop
docker compose -f docker-compose.prod.yml down
docker compose -f docker-compose.prod.yml up -d
```

### 🔴 Место на диске заканчивается

```bash
# Посмотреть размер бэкапов:
du -sh /opt/kaza_shop/backups/

# Удалить бэкапы старше 7 дней:
find /opt/kaza_shop/backups -name "*.tar.gz" -mtime +7 -delete
```

### 🔴 SSL-сертификат перестал работать

```bash
certbot renew --force-renewal
systemctl reload nginx
```
